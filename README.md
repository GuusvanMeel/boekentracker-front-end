# Boekentracker

De **Boekentracker** is een **Progressive Web App (PWA)** die is ontwikkeld als onderdeel van het vak **Front-End Development – Semester 3**.  
Dit project is gemaakt voor school en richt zich op het ontwerpen en ontwikkelen van een gebruiksvriendelijke front-end applicatie met moderne webtechnologieën.

De applicatie fungeert als een **digitale boekenkast**, waarin gebruikers hun boeken kunnen bijhouden en organiseren.

---

## Functionaliteit

Met de Boekentracker kan een gebruiker:

- Boeken zoeken via een externe boeken-API  
- Boeken toevoegen aan een persoonlijke library  
- Aangeven welke boeken:
  - momenteel worden gelezen  
  - nog gelezen willen worden  
  - zijn uitgelezen  
  - zijn gestopt  
- Boeken beheren vanuit verschillende overzichten  
- Een willekeurig boek kiezen om te gaan lezen via een interactief draaiwiel  
- De applicatie gebruiken als **PWA** op desktop en mobiel

---

## Technologieën

Dit project is gebouwd met de volgende technologieën:

- **React**
- **Next.js**
- **JavaScript / TypeScript**
- **NoSQL database (MongoDB)**
- Progressive Web App (PWA)
- CSS / moderne UI-componenten
- Hosting via **Vercel**
